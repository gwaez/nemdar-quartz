# nemdar-quartz

Quartz static site for **Nemdar Brain** (`brain.nemdar.tech`).

Public reading UI for the Nemdar second brain, built with [Quartz v4](https://quartz.jzhao.xyz/) and served via nginx on port 80.

| Role | URL |
|------|-----|
| **Quartz (this app)** — public read | https://brain.nemdar.tech |
| **SilverBullet** — write/edit | https://sb.nemdar.tech |

See [DEPLOY.md](DEPLOY.md) for Coolify/Docker deploy notes.
